이 페이지는 외부 서버와 통신하지 않습니다. 파일 하나만 있으면 인터넷 없이도 그대로 작동합니다.

방법 1 · 파일을 그대로 보내기

이 페이지를 여행비교.html 로 저장해 단톡방에 파일로 올립니다. 친구들이 내려받아 열면 끝입니다. 어디에도 올리지 않아 가장 간단하지만, 아이폰에서는 파일 앱을 거쳐야 해서 조금 번거롭습니다.

방법 2 · 깃허브 페이지로 링크 만들기
  1. 깃허브에서 저장소를 새로 만들고 Public 으로 둡니다.
  2. 파일을 index.html 이라는 이름으로 올립니다.
  3. Settings → Pages → Source 를 main 브랜치로 지정합니다.
  4. 몇 분 뒤 아이디.github.io/저장소이름 주소가 열립니다. 이 주소를 단톡방에 올리면 됩니다.

공개 저장소라 누구나 코드를 볼 수 있지만, 여기에는 비밀번호도 API 키도 없어 문제되지 않습니다. 주소를 아는 사람만 찾아올 수 있고, 한 번 만들면 계속 유지됩니다.

방법 3 · 넷리파이 드롭

가입 없이 app.netlify.com/drop 에 파일을 끌어다 놓으면 즉시 주소가 생깁니다. 가장 빠르지만 가입하지 않으면 주소가 일정 시간 뒤 사라집니다.
